Política de privacidad

Dashboard Personal es una aplicación privada que funciona localmente en el dispositivo del usuario.

Información utilizada

La aplicación solicita acceso de solo lectura a Google Calendar para consultar y mostrar los eventos del usuario.

Uso de la información

Los datos obtenidos de Google Calendar se utilizan exclusivamente para mostrar actividades y eventos en el dashboard local.

Almacenamiento

Las credenciales OAuth se almacenan localmente. Los datos del calendario no se publican en este sitio web.

Compartición de datos

La aplicación no vende ni comparte los datos de Google Calendar con terceros.

Revocación de acceso

El usuario puede revocar el acceso desde la configuración de seguridad de su cuenta de Google.
